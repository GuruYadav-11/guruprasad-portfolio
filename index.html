Projects

PATHWAY

Personal Process Navigator

"Complex processes. Clear next steps."

Pathway transforms complicated real-world application processes such as scholarships, internships, college admissions, and government services into a clear, step-by-step process. Users can select a process, complete an eligibility diagnostic, and work through a prerequisite checklist to identify what they need before reaching the official application gateway.

Status: Complete Working Product Prototype (Final Implementation Phase)
Technologies: HTML5, CSS3, JavaScript, GSAP 3.12

Student Management Interface

Flexbox Quest

Mini Game UI

"Learn Flexbox by building a game interface."

A mini game interface created to practice CSS Flexbox concepts. The project includes a game header, player area, controls, inventory, quests, responsive layouts, and a display property experiment covering block, inline, inline-block, and flex layouts.

Status: Completed WebDev101 Assignment
Technologies: HTML, CSS, Flexbox
